### Projects
 
**[ChessOS](https://github.com/O-Ayyad/ChessOS)**
A bootable 64-bit chess operating system. It has a custom BIOS bootloader, graphics, PS/2, and AC'97 audio drivers. The chess engine plays at 2750 Elo, with difficulty levels from beginner to master.
`C++` `x86-64 Assembly` `NASM` `QEMU`
 
**[SixDegrees.lol](https://sixdegrees.lol)**
A full-stack app for exploring player relationship graphs within Riot Games player profiles. A rate-limited ingestion pipeline syncs live Riot Games API data into Neo4j.
`Python` `FastAPI` `JavaScript` `Neo4j` `Docker`
 
**Composite Inventory**
A production inventory app used daily by small business customers. It keeps stock consistent across concurrent sessions and syncs listings with the Amazon, eBay, and Walmart APIs.
`Java` `Swing` `Maven`
